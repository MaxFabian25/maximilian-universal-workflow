# Ideation Paths

Use repo evidence to create options across axes such as conservative/balanced/ambitious, minimal/complete, local/systemic, quick fix/refactor, artifact-only/source-changing, and sequential/parallel.

Each implementation-path choice should include:

- label;
- what it optimizes for;
- repo evidence or constraint;
- tradeoff;
- risk;
- why it is or is not recommended.

Convergence output:

- selected direction;
- rationale;
- rejected alternatives worth preserving;
- assumptions;
- constraints;
- risks;
- acceptance criteria;
- allowed side effects;
- updated phase bundle;
- next planning questions.

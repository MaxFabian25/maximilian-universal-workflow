# Cleanup Playbook

Use `../../../docs/workflow-contracts/information-structure.md` to classify file role, file placement, duplicated authority, and structural risk before cleanup.

## Candidate Sources

Old plans, abandoned notes, stale `workflow-artifacts/`, copied prompts, duplicate summaries, temporary ledgers, ownerless generated reports, and scratch files under `.agents/`, `docs/plans/`, `docs/archive/`, `tmp`, or repo-specific agent folders.

## Classification

- Live authority: current rules/specs/source docs; keep.
- Useful archive: label or archive.
- Stale bloat: delete after approval.
- Generated evidence: regenerate or delete if stale.
- Uncertain: ask.

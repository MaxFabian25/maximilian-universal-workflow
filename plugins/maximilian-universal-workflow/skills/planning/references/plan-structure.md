# Plan Structure

Use this structure for decision-complete repo plans.

Use `goal-planning/references/goal-plan-structure.md` when planning should output a goal-prefixed execution prompt.

## Required Fields

- Goal
- Exploration evidence: files inspected, commands run, explorer summaries if any, and unresolved evidence gaps
- Approved direction
- Repo state and branch assumption
- Scope and non-goals
- Files or areas to create/modify
- Task order
- Ownership model
- Verification commands or checklists
- Review expectations
- Handoff target
- Open questions that block execution

## Artifact Use

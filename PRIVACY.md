# Privacy Policy

Maximilian Universal Workflow is a Codex plugin made of local workflow instructions, documentation, and validation assets.

The plugin does not include a hosted service, telemetry endpoint, analytics SDK, remote database, or credential collection flow. It does not independently collect, store, sell, or transmit personal information.

When you use the plugin in Codex, your interaction is governed by the Codex/OpenAI environment, any enabled connectors, your local repository contents, and your own runtime configuration. Do not put secrets, private credentials, or unrelated personal data into plugin marketplace metadata or public repository files.

Questions about this policy can be raised in the repository issues at https://github.com/MaxFabian25/maximilian-universal-workflow.
